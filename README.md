# Floating VoiceBubble

Floating VoiceBubble is an Android voice-input application focused on high final accuracy, true real-time partial transcription, near-zero running cost, and eliminating perceived waiting time.

The authoritative product requirements and design policy live in the project Notion page. Repository documentation describes implementation details only; it does not override that specification.

Development starts at production-quality scope: cloud BYOK and fully offline operation are first-class modes, user register/tone must be preserved, and the personal dictionary is designed without an artificial small-entry ceiling.
